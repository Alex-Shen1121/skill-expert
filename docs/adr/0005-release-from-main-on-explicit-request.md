# 仅在明确授权后从 main 发布稳定版本

Agent 技能管家是个人维护的小型软件，持续维护双分支晋级、开发序号和候选资产搬运的成本高于它们带来的收益。所有变更继续通过 `codex/*` PR 合入 `main`，普通 PR 保持稳定版本号并只运行轻量检查；只有用户明确要求发布时，才通过发布准备 PR 更新稳定版本，并由绑定该 PR 合并提交和三项成功检查的手动工作流一次构建、签名、回验和公开四平台资产。旧 `release` 分支暂时保留但不再参与任何版本或发布决策；不可变 tag、生产密钥边界、Draft 回验、校验和与来源证明继续保留。
