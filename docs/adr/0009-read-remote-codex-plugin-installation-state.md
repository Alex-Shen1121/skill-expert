# 从 App Server 补全 Codex 远程插件安装状态

Agent 技能管家以 App Server 的只读 `plugin/installed` 单次结果生成“已安装”视图，完整保留其中确认的本地与远程安装实体，并按 Agent、Marketplace 与插件 ID 保留独立身份。现有 `codex plugin list --available --json` 继续提供“可安装”目录，并在 App Server 接口不可用时回退为本地已安装的部分结果。两个来源独立读取；任一来源失败都不得丢弃另一来源已经确认的状态。该接口仍在开发中，因此适配器必须隔离协议变化：回退时将投影标为部分结果并提供重试，不得扫描缓存或用当前 Codex 界面的可见数量推断安装状态。

本次不扩展“可安装”视图的远程目录范围。App Server 的远程目录查询口径与本地 Marketplace 不一致，待官方接口稳定且产品范围另行确认后再接入。

完整结果直接显示精确数量；回退结果显示“至少 N 个”并说明远程状态未读取。远程插件先使用 `plugin/installed` 的概要资料进入列表和基础详情，选中后再通过只读 `plugin/read` 加载插件内置能力，并只在当前页面内缓存；详情读取失败不移除已经确认的安装实体。同名但属于不同 Marketplace 的安装与可安装条目保持独立，并明确展示各自来源。

官方状态返回的远程 HTTPS 图标可由界面直接显示，加载失败时使用默认图标。本地不支持的视觉格式同样使用默认图标；单独的视觉资源降级不再降低插件详情完整性，只有说明或插件内置能力等实质资料无法可信读取时才显示详情警告。
