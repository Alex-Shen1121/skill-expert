# Triage 标签

Agent Skills 使用五种固定的内部角色。

下表规定这些内部角色在本项目中对应的 GitHub 标签名称。

| Agent Skills 内部角色 | GitHub 中文标签 | 说明 |
| --- | --- | --- |
| `needs-triage` | `待判断` | 新问题，还没有决定怎么处理 |
| `needs-info` | `信息不全` | 需要提出问题的人补充信息 |
| `ready-for-agent` | `Agent 可处理` | 信息完整，可以交给 Agent 处理 |
| `ready-for-human` | `人工处理` | 需要开发者亲自判断或操作 |
| `wontfix` | `不予处理` | 已决定不处理这个问题 |

当 Skill 提到英文内部角色时，必须使用表中对应的中文 GitHub 标签。

如果以后修改了 GitHub 标签名称，也要同步修改本表。
