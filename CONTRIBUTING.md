# Contributing to Skill Expert

Thank you for helping improve Skill Expert.

- Report reproducible bugs and propose scoped changes in the
  [Skill Expert issue tracker](https://github.com/Alex-Shen1121/skill-expert/issues).
- Use [Discussions](https://github.com/Alex-Shen1121/skill-expert/discussions) for
  questions and early ideas that are not ready for an issue.
- Open changes against `main` through
  [pull requests](https://github.com/Alex-Shen1121/skill-expert/pulls), and include
  the relevant issue plus the verification you ran.

See [AGENTS.md](AGENTS.md) for this repository's implementation and review
workflow. Skill Expert keeps its product decisions, releases, and update channel
independent from the upstream project.
