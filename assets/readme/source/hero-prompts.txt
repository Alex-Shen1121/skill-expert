Use case: identity-preserve
Asset type: GitHub README Hero 的角色图层
Input images: Image 1 是 assets/icon.png，用作角色身份与画风锚点，不是需要直接修改的最终画布
Primary request: 延展同一位角色为四分之三身站姿，身体略微朝右，视线看向右侧的技能库面板，右手用星星魔法棒指向右上方的连接路径，动作自然、自信、友好
Subject: 保持相同的桃棕色长卷发、暖棕色眼睛、星星耳饰、深色绒领、带粉彩星星装饰的白色冬装，以及粉色星星魔法棒
Style/medium: 与参考图一致的精致日系动画插画；干净轮廓；适合作为深色技术产品 Hero 的角色剪影
Composition/framing: 四分之三身，完整保留头发、双手和魔法棒；适配约 310 × 350 的竖向预留区域；主体居中并保留安全边距；角色朝右；轮廓清晰
Lighting/mood: 面部保持温暖柔和；右侧带克制的青色与紫色边缘光；聪明、可靠、轻快
Color palette: 桃棕、奶油白、薰衣草紫、青色和少量星光蓝；不要让高光吞掉白色衣服边缘
Constraints: 只出现一个角色；严格保持脸部、发型、服装、配饰、比例和性格，不重新设计角色；不得裁切魔法棒；不得增加第二个角色或无关道具
Avoid: 文字、字母、数字、徽标、水印、界面、背景场景、地面、投影、底座、边框、发光文字、额外手指、变形手部
